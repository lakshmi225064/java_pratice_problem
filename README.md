# JavaScript Practice Problems

This repository contains JavaScript solutions to the practice problems provided for the ICT Academy of Kerala MERN Stack Skill Enhancement course.

## Contents

- `question1.js` — Print numbers from 1 to 10
- `question2.js` — Find the sum of an array
- `question3.js` — Find the largest number in an array
- `question4.js` — Check whether a number is even or odd
- `question5.js` — Reverse a string
- `question6.js` — Merge arrays using the spread operator
- `question7.js` — Filter even numbers using ES6
- `question8.js` — Use template literals
- `question9.js` — Rewrite a function as an arrow function

## Language

JavaScript (ES6+)

## How to run

If Node.js is installed, open a terminal in this folder and run a file, for example:

```bash
node question1.js
```

Replace `question1.js` with the file you want to run.

## Note

The supplied PDF contains Questions 1–9. Add `question10.js` if your assignment includes a tenth question not present in that PDF.
